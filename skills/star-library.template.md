# Skill: STAR Story Library

**Always active when generating interview prep.** This file contains pre-written STAR stories and analytical frameworks from your past interview preparation. Use these as the primary source for behavioural answers — prefer a story from here over generating a new one. Only generate new stories when no entry maps to the question at 70%+ relevance.

Each story follows the **C/T/A/R/L format** (Context, Task, Action, Result, Learning). Results use only real metrics from `context/profile.md`.
