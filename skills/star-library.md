# Skill: STAR Story Library

**Always active when generating interview prep.** This file contains pre-written STAR stories and analytical frameworks extracted from past interview preparation. Use these as the primary source for behavioural answers — prefer a story from here over generating a new one. Only generate new stories when no entry maps to the question at 70%+ relevance.

## Analytical Frameworks

### QC / Grocery GMV Diagnostic Tree
Use when asked to diagnose flat GMV or underperformance in a grocery/quick commerce vertical.

```
GMV = Orders × AOV
Orders = (Sessions × CVR) × Frequency
  Sessions → channel breakdown (PM, CRM, in-product), competitive landscape
  CVR → delivery fees, assortment, delivery times, incentive efficiency
  Frequency → M1/M3/M6 cohort retention, subscription effects, habit loops
AOV = (ABV + Service fee + Delivery fee) − Incentives
  ABV → price parity, availability, category mix
  Incentive usage → CARC/GMV ratio, promo sensitivity
```

**If Food GMV growing but QC flat → check in this order:**
1. Exposure: QC impression share vs food, homescreen placement, CRM prioritization
2. Conversion: delivery fee, assortment gaps, AOV thresholds
3. Retention: cohort repeat rate, habit formation, use case fit mismatch (planned vs impulse)

---

### Retention Drop Framework
Use for case questions: "Retention has dropped X%, what do you do?"

1. Rule out external variables: seasonality, competitive moves, supply changes
2. Segment the drop: new vs retained vs churned cohorts; channel-level breakdown
3. Funnel diagnosis: acquisition quality → activation → M1/M3 retention → reactivation
4. Hypothesize: experience issue vs incentive issue vs commercial/supply issue
5. Design experiments: holdout groups, A/B on specific levers, incrementality measurement
6. Define success: incremental orders/GMV, not just absolute volume recovery

---

### Incentive Evaluation Framework
Use when asked about incrementality, discount ROI, or promo efficiency.

- **Incrementality first:** Does this campaign drive orders that wouldn't have happened otherwise? Use holdout groups.
- **Value segmentation:** Which cohorts are incentive-dependent vs converting organically? Segment before setting offer depth.
- **CARC/GMV ratio:** Core efficiency metric — cost as a % of the GMV generated.
- **Payback window:** Reactivated users should generate enough repeat orders to recover incentive cost within a defined window (e.g. 90 days).
- **Contamination check:** Are users receiving multiple incentives across campaigns? Dynamic exclusion logic in Braze prevents this.

### Subscription Growth Framework
Use for questions about growing a membership or freemium-to-premium conversion.

```
Short-term:
  Commercial: fund exclusive offers on best-performing vendors
  Marketing: push PM campaigns, add supplementary comms for freemium-to-premium
  Pricing: add longer trial periods, re-offer trial for churned users

Medium-term:
  Commercial: expand assortment (frequency drivers, category mix)
  Marketing: double down on high-value user cohort (lowest-hanging fruit)
  Pricing: test longer-term plans, reverse trial experiments

Long-term:
  Commercial: vendor coverage + inventory assortment + co-funding framework
  Marketing: GTM for always-on exclusive deals (subscribers: confirmation; non-subscribers: FOMO)
  Pricing: improve margins from supply side, transfer value to customers
```

**Key principle:** Subscription primarily impacts frequency and retention, not acquisition.
