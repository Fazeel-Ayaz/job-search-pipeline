# Skill: Archetype Detection & Resume Framing

**Always active.** Run archetype detection on every JD before writing a single resume bullet or summary line. Archetype determines which experience leads, which gets compressed, what the summary angle is, and which bracket tags to use. This is a structural framing step that runs before keyword injection.

## Your Archetypes

The setup wizard defines 3–5 archetypes here — each one represents a different hiring manager's
mental model of the ideal candidate. The same underlying experience is foregrounded or backgrounded
differently depending on which archetype the role belongs to.

Each archetype includes:

- **Buyer:** who hires this person and what mental model they have
- **JD detection signals (any 2+ = this archetype):** phrases that signal this archetype in a JD
- **Summary angle:** how to open the resume summary for roles of this type
- **Lead experience:** which tagged entries from `context/profile.md` to foreground (positions 1-2 per role block)
- **Compress or omit:** which tagged entries to deprioritize
- **Bracket tags to use:** `[Bold Category Tags]` for bullets
- **Archetype code:** short ID used in Notion logging (e.g. `CRM-STRAT`)

## Detection Workflow

### Step 1: Scan the JD for signal clusters

Read the full JD and count detection signals for each archetype. Signals are case-insensitive.
A single JD can trigger multiple archetypes — most roles are hybrids.

### Step 2: Rank archetypes by signal count

Build a signal-count table for each archetype. Primary = highest count. Secondary = second highest (if ≥2 signals).

### Step 3: Assign primary and secondary archetype

- **Primary archetype** (highest signal count): Drives summary angle, which experience leads, which bracket tags dominate.
- **Secondary archetype** (second highest, if ≥2 signals): Contributes 1–2 bullets and secondary bracket tags. De-emphasised but present.
- If only one archetype has ≥2 signals: single-archetype framing.

### Step 4: Apply framing before keyword injection

1. Set the summary angle from the primary archetype
2. Reorder experience bullets: primary archetype's "lead experience" goes to positions 1-2 in each role block
3. Compress bullets from the "compress or omit" list of the primary archetype
4. Apply primary archetype's bracket tags to the leading bullets
5. Inject secondary archetype's framing into bullet positions 3-4 per role
6. Then run normal ATS keyword injection on top

### Step 5: Output the archetype call

At the top of the resume generation output, always state:

```
Archetype detection:
  Primary: [ARCHETYPE-CODE] — [N] signals: [list signals found]
  Secondary: [ARCHETYPE-CODE] — [N] signals: [list signals found]
  Framing: [one sentence on how this shapes the resume]
```
